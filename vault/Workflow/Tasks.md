# Tasks

Small things that are not Jira tickets and not a workstream's single next action. One line each. Add the workstream as a link when there is one, and a date as `📅 YYYY-MM-DD` when it matters. `/standup` shows "Next" on the Dashboard and puts dated items in Upcoming. `/weekly` moves ticked items to Done and prunes "Later". If an item sits in Next for three weeks, it is either a Jira ticket or not real.
